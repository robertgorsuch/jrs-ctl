# ADR-0002: x86_64 only

Status: accepted · Date: 2026-09-08 · Spec: §1.2, §1.3

## Context
Draft 1.0 targeted x86_64 and ARM64 on both Windows and Linux.

## Decision
Build and test Windows and Linux on x86_64 only.

## Consequences
JasperReports Server is supported on x86_64, so ARM64 builds would run where the server cannot. Halves the distribution matrix and the installer smoke tests. The build is architecture-neutral Java; adding ARM64 later is a packaging change only.
